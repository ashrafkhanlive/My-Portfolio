# The Developer Behind the Screen 💻

_"Hi, I'm Ashraf Khan."_

No... I'm not the guy who fixes printers.

No... I don't hack Wi-Fi passwords either.

And yes... my family still thinks **"Java" means coffee.** ☕

I'm **Ashraf Khan**, currently pursuing my **Bachelor of Computer Applications (BCA)** from **Indira Gandhi National Open University (IGNOU)**.

Being an IGNOU student means you're basically the **CEO of your own education**. Nobody is going to remind you to study. No daily attendance. No classmates asking, _"Bhai, assignment complete?"_

It's just you...

Your laptop...

A million browser tabs...

And Stack Overflow becoming your best friend.

I knew one thing very early:

**Theory alone wasn't going to land me a software developer job.**

So I decided to stop just reading code...

...and start writing it.

That's when I joined the **Java Full Stack Development Program at TAP Academy**.

Looking back, it turned out to be one of the best decisions of my learning journey.

---

## 💻 Why Java Full Stack?

Let's be honest.

Companies don't hire developers because they can write:

```java
System.out.println("Hello World");
```

They hire people who can build products that solve real problems.

I wanted to understand the complete picture:

- 🎨 Frontend
- ⚙️ Backend
- 🗄️ Database
- 🔐 Authentication
- 🚀 Deployment

Instead of becoming "just a Java developer," I wanted to become someone who could build an application from login page to production server.

## 🚀 Projects > Certificates

One lesson changed my mindset completely:

> **Certificates tell people you've learned. Projects prove you actually can.**

So instead of collecting certificates, I focused on building projects.

Some of my favorites are:

- 💼 **LinkedIn Clone**
- 🏨 **Hotel Booking Platform**
- 📚 **Uber Clone Platform**
- 🔐 **Authentication & Authorization System**
- 🌐 **REST API-Based Applications**

These projects taught me things no textbook ever could:

- Database Design
- API Integration
- Authentication & Authorization
- Clean Architecture
- Debugging
- Deployment
- Writing Production-Ready Code

Nothing beats the feeling of seeing your own application actually working.
